# 热点问题与选题机会地图

基线日期 2026-09-10。这里是根据 2026 官方 CFP 与 ACL 已接收题目形成的**定性问题地图**，并非六会论文普查、频率统计或录用趋势预测。
方向存在性主要见 P04、P05、P07、P12、P15、P16；下表的研究切口和实验建议全部为 S/H。没有证据支持“这些题容易中”。

## 从热词到研究问题

| 方向 | 值得检验的问题（H） | 最有区分力的设计（S） | 主要风险 |
|---|---|---|---|
| 推理与 test-time compute | 更多推理预算何时失去收益？ | 匹配预算，分难度，比较搜索／重采样／自检 | 把更多 token 的收益归于新机制 |
| LLM agents | 长程失败来自规划、记忆还是反馈？ | 故障注入、轨迹审计、单项能力受控替换 | 只报最终成功率，忽略失败重试 |
| RAG 与长上下文 | 错误来自不可检索还是未使用证据？ | 控制证据可得性、位置和干扰 | 用答案重合代替证据真实性 |
| 评估与 LLM judge | judge 是否偏好风格而非正确性？ | 保持事实不变干预风格；盲化人评 | 循环使用同类模型互相评分 |
| 多语言／低资源 | 改进来自语言知识还是数据量？ | 控制资源差异、分语言错误分析 | 将英语基准机器翻译即声称跨文化有效 |
| 可解释性与机制 | 发现的特征是否具有功能作用？ | 干预、反事实、跨设定检验 | 用可视化或相关性宣称机制因果 |
| 对齐与安全 | 优化某种安全指标是否转移风险？ | 威胁模型、分布变化、能力—风险权衡 | 只选容易防御的攻击或单一代理指标 |
| 合成数据与后训练 | 合成数据何时提升覆盖而非重复偏差？ | 控制量与质量、去重、分布外评测 | 测试污染，生成与评估共源 |
| 高效学习与推理 | 小模型／压缩方法在哪些成本条件更好？ | 按主张比较相应成本；权衡主张用 Pareto 曲线 | 将特定硬件或 batch 的优势外推为普遍结论 |
| 多模态与 grounding | 模型真正使用哪种模态信息？ | 缺失／冲突模态对照、信息泄漏审计 | 语言先验解决了所谓多模态任务 |
| AI for science／应用 | 领域约束能否引出新的学习问题？ | 专家定义目标、真实约束与外部验证 | 通用模型套领域数据，贡献只剩包装 |
| 理论／优化／概率／RL | 哪个假设失效限制了现有保证？ | 反例、界的比较、受控模拟或证明 | 为追 LLM 热点硬改问题叙述 |

保留非热点但重要的问题：传统 NLP、形式语言、优化基础、概率模型、负结果和严谨复现。领域热度不替代问题价值。

## 动态刷新方法

选题时只刷新相关方向：目标会最近已完成一届的官方论文集／程序＋当前 CFP＋必要最近邻正文。对 NeurIPS 尚未公布结果的届次，不称其为已录用趋势。

如需数量性热点分析，先定义：会议、年份、track、正文还是题目摘要、去重规则、分母、缺失项、标签是否多选。记录采样清单后再计数；CFP 列出的方向只是征稿范围，奖项是选择性样本，二者不能冒充频率证据。

热点建议最终落到一张机会卡：现有局限｜候选解释｜最近邻｜可验证差异｜最小试验｜资源｜放弃条件。无法说明差异时，先做文献和失败案例调查，不急着命名新方法。
