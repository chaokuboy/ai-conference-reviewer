# 投稿要求与实践

每次实际投稿先按年份与 track 更新官方要求。以下是检查框架，不是六会通用规则清单；不把 2026 快照当成 2027 规则。

## 必须分别核验的字段

| 字段 | 为什么单独核验 |
|---|---|
| 会议届次、track、主会／Findings／workshop | 学术范围、流程和单位认定不同 |
| 摘要、全文、附件、commitment、回复、终稿时间 | 不一定同一天；AoE 是 UTC−12，换算北京时间加 20 小时 |
| 正文页数、参考文献、限制、伦理与附录计数 | 同样的“8 页”可能排除项目不同 |
| 模板、匿名、仓库与数据链接 | 预印本允许不等于投稿稿件可不匿名 |
| 原创、同期投稿、已有 workshop／期刊版本 | 要看重叠程度与官方例外 |
| 作者名单、OpenReview 资料、COI、reviewer 注册 | 科学质量之外也可能影响行政资格 |
| 数据／代码、伦理、责任清单、AI 使用披露 | 有不同说明义务；不能一概写“必须全开源” |
| rebuttal 是否允许新实验／新版／附件 | 不同会议和年份可不同 |
| 注册、展示、camera-ready、授权 | 录用后发表条件也要完成 |

输出时每项标注“已核验／待核验／不适用”、官方链接、访问日期、适用版本。政策冲突优先同届对应 track 的明确更新，不在未读官方原文时保证“可直接提交”。

## 历史资料与待复核线索

以下条目保留原采集范围，不能仅凭本表视为投稿资格已核验。P 编号关联账本；实际给出硬规则时逐项补齐支持段落、读取范围、适用版本和核验日期。

- ICML 2026 主会：正文 8 页，参考文献、impact statement、附录另计；最终版正文多 1 页；附件与正文同文件且无单独附件截止（P07）。实际投稿仍读 Author Instructions。
- EMNLP 2026：ARR 评审与会议 commitment 是两阶段；2026 May cycle 有提交时指定 EMNLP 的绑定安排，早先周期的稿件不适用该条（P05）。不要推广为所有 ARR 周期的永久规则。
- ICLR 2026（仅摘要／检索线索，未完成对应原文核对）：检索材料指向 OpenReview 双盲及讨论期间可修订稿件安排（P11）。具体开放状态和截止应查同届后续通知，不能据原计划保证窗口仍开放。
- NeurIPS 2026：贡献类型和独立 tracks 要分开；P13 仅已定位 Evaluations & Datasets 指南入口、细则待复核（P12/P13），不能沿用旧 track 名称与规则。
- AAAI-26：有两阶段评审及当届 AI 试点（P14）；流程安排不代表科学评价降低标准。
- ACL 2026：主会使用 ARR 与 commitment；具体 CFP 与 ARR 通用要求共同适用（P04）。

## 经验凝练（S）

把截止前工作按依赖安排，而非平均分周：

1. 先确定核心贡献和最近邻；若差异不存在，尽早停下重设。
2. 先跑能推翻解释的强基线或控制实验；核心解释失败时，扩充数据集不能自动补救。
3. 核心证据稳定后再扩展覆盖面；把实验预算留给最关键的不确定性。
4. 主文让读者看清问题、差异、决定性证据和限制；详细复现实验放在允许的位置并明确引用。
5. 投稿前做一次主张审计和一次格式／资格核对；不要把核心研究完成寄托于 rebuttal。
6. 预留回复期团队时间和原始结果索引；最终回复以实际证据为中心。

当用户问“发表情况／录用率”时查官方主席总结或论文集前言。仅报告已核验的年份、track、有效投稿与录用口径。例：C01 的 NeurIPS 2025 主会为 21,575 份有效投稿、5,290 录用、24.52%；该总体统计不能换算个人录用概率，也不能拿去代表 2026 或其他 track。
